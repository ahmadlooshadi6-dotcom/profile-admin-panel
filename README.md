# پروفایل فارسی و پنل ویرایش نمایشی

یک صفحهٔ پروفایل واکنش‌گرا با متن فارسی و پنل ویرایش ساده، ساخته‌شده با Next.js و Tailwind CSS.

## اجرای محلی

نیازمند Node.js است. در پوشهٔ پروژه اجرا کنید:

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید. برای ساخت نسخهٔ آمادهٔ انتشار از `npm run build` استفاده کنید.

## پنل مدیریت

دکمهٔ «ویرایش پروفایل» پنل را باز می‌کند. اطلاعات ویرایش‌شده در localStorage همان مرورگر ذخیره می‌شود. این نسخه فقط نمونهٔ رابط کاربری است: ورود امن، حساب کاربری، پایگاه داده یا آپلود فایل ندارد. برای استفادهٔ واقعی و عمومی باید احراز هویت سمت سرور و ذخیره‌سازی امن اضافه شود.

## انتشار

مخزن را در سرویس میزبانی سازگار با Next.js مانند Vercel وارد کنید و از دستورهای پیش‌فرض `npm install` و `npm run build` استفاده کنید. این مخزن به‌تنهایی یک لینک سایت زنده تولید نمی‌کند؛ بعد از استقرار، سرویس میزبانی URL سایت را می‌دهد.
